# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to the label used in GitHub Issues.

| Canonical role    | GitHub label      | Meaning                                   |
| ----------------- | ----------------- | ----------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue    |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent    |
| `ready-for-human` | `ready-for-human` | Requires human implementation             |
| `wontfix`         | `wontfix`         | Will not be actioned                      |

When a skill names a canonical role, apply the corresponding GitHub label.
